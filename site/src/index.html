quickertype

Source on GitHub
Engine

Both run in your browser: quicktype is quicktype's original TypeScript engine, quickertype its Rust port, compiled to WebAssembly. Switch between them to compare; warm runs are the runs after the first, with the engine loaded and compiled.

General options

quicktype's run-level options, for every language, as on its command line.

Input

Large files are not shown in the editor, which would slow the page down. They run all the same.

Drop a JSON or JSON Schema file
Drop a file anywhere on this side. TypeScript input needs the TypeScript compiler, which doesn't run in the browser; the CLI has it.
